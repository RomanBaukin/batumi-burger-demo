# Согласованный бриф

- Цель: портфолио создания лендингов целиком для малого бизнеса разных ниш.
- Вымышленная дерзкая городская бургерная в Батуми. Название и типографический логотип создаёт Codex.
- Русский язык, цены в лари (₾). Без реальных контактов, выдуманных отзывов и наград. Явное обозначение демопроекта.
- Реалистичный адаптивный сайт с одним-двумя выразительными решениями: крупная типографика, тёплая палитра, сгенерированные изображения еды в единой стилистике.
- Структура: первый экран → меню → ингредиенты и приготовление → история бренда → доставка → FAQ → подвал с отметкой демо и ссылкой на автора.
- Меню: 6 бургеров (включая острый и вегетарианский), 3 закуски, 3 напитка. Состав, цена, добавление в корзину.
- Корзина: количество, удаление, сумма, сохранение в браузере. Оформление показывает сообщение о демо, без платежей и сбора персональных данных.
- Умеренные анимации; учитывать prefers-reduced-motion.
- Next.js + TypeScript, меню в проекте, без базы данных.
- Публичный GitHub, изменения через PR, Vercel preview для PR, автодеплой main.
- Дедлайна нет. Пользователь дал команду начать реализацию 29 сентября 2026 года.
