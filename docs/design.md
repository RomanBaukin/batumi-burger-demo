# ЖАР — дизайн и реализация

Утверждённый бриф: docs/brief.md. Пользователь дал команду начать 29 сентября 2026.

Городская бургерная в Батуми. Название «ЖАР», подпись «Бургеры у Чёрного моря». Угольный фон, томатно-красный акцент, молочный текст. Крупный узкий кириллический гротеск для заголовков, спокойный гротеск для текста. Скругления кнопок 8px, изображения 12px. Контрастная фотография еды, асимметричный первый экран. DESIGN_VARIANCE 7, MOTION_INTENSITY 3, VISUAL_DENSITY 4.

Статические секции рендерятся сервером. Каталог и корзина — отдельный клиентский компонент. Данные меню типизированы, состояние корзины сохраняется в localStorage и проверяется при чтении. Повреждённые данные игнорируются. Недоступность localStorage не блокирует заказ. Native dialog обеспечивает фокус, Escape и модальность. Оформление — только подтверждение демонстрации, без персональных данных.

Этапы: изображения и шрифты; страница и каталог; корзина; мобильная адаптация; проверки функций, клавиатуры и переполнений; PR, preview и публикация. Проверки: unit-тесты восстановления корзины и расчётов, браузерные тесты категорий, количества, сохранения, оформления, мобильной навигации; lint, build, typecheck. Отметка демопроекта видна на странице и при оформлении. Никаких фиктивных отзывов, адресов или платёжных форм.
